# Publication checklist

Before making a public GitHub repository:

- Remove all private LAN IPs.
- Remove local usernames and absolute paths.
- Remove screenshots, serial numbers, packet captures, and browser logs.
- Remove email addresses and support-ticket evidence.
- Use placeholders in scripts and docs.
- Verify the USB payload does not contain owner-specific paths.
- Explain that the workflow is for owner-operated devices only.
- Include a rollback or rescue path.
- Test a fresh clone locally.
